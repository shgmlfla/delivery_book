[인원]

1명 (백엔드 1명)

[주요 개발 기능]

- Spring Security 및 jWT를 활용한 인증•인가 기능 구현
- 도서 API를 활용한 REST API 기능 개발
- 토스 페이먼츠를 활용한 결제 시스템 구현
- 카카오 API를 활용한 배송지 관리 시스템 구축
- 보조적으로 Gemini를 활용한 프론트 화면 구현
